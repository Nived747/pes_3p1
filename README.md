# pes_3p1
this repo is created for 5 days of training for 3rd sem students of PES Mandya.  It was held in 1st week of Nov 2026. The content was git and commands, core python concepts, problem solving on loop, recursion, arrays and strings. We also learnt basic DSA

## Steps to create Git Personal Access Token (PAT):
    Click profile picture (Top right corner)
	Next page, scroll down click developer settings
	Next page click Personal access tokens and select classic
	Next page click generate new token and select classic
	Next page, give note, select no expiray, select Repo checkbox
	Copy the PAT and mail it to your self with git_pat/git pat
